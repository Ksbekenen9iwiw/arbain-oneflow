# Komponen pihak ketiga

Paket source tidak menyertakan runtime atau source dependensi. Instalasi mengambil versi pada requirements.lock; metadata/lisensi asli dependensi tetap berada dalam distribusi masing-masing.

| Komponen | Versi terpasang saat verifikasi | Metadata lisensi |
|---|---|---|
| Django | 5.2.18 | BSD-3-Clause |
| asgiref | 3.12.1 | BSD-3-Clause |
| sqlparse | 0.6.0 | Lihat LICENSE dalam distribusi sqlparse |
| tzdata | 2026.5 | Apache-2.0 |

Python 3.12 dan SQLite disediakan lingkungan pengguna, bukan dibundel. Bila tim kelak mendistribusikan runtime atau dependensi, sertakan notifikasi dan teks lisensi yang diwajibkan distribusi tersebut.

Kode aplikasi, UI Bahasa Indonesia, aturan, dataset uji, dan dokumentasi dalam paket ini merupakan keluaran pengembangan MVP. Tim perlu mencatat kontribusi nyata anggota, bantuan AI, asal aset, perubahan versi, dan ketentuan penyelenggara sebelum membuat klaim komponen lokal atau KI. Dokumen ini tidak mengklaim persentase komponen lokal atau hak yang sudah tercatat.
