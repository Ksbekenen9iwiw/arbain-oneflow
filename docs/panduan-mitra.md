# Panduan OneFlow untuk mitra (tanpa teknisi IT)

Panduan ini untuk pemilik usaha atau Manajer. Tidak ada langkah yang butuh
mengetik perintah atau membuka server.

## Sehari-hari

| Mau apa | Caranya |
|---|---|
| Masuk | Buka alamat web OneFlow, isi nama pengguna dan password. |
| Pasang di ponsel | Buka webnya di Chrome, menu titik tiga, **Tambahkan ke layar utama**. |
| Tambah pengguna | Menu **Pengguna** → **Tambah pengguna**. Isi nama, nama pengguna, dan peran. OneFlow menampilkan password sementara sekali; salin dan kirim ke orangnya. |
| Ada yang lupa password | Menu **Pengguna** → **Buat ulang password** di baris orang itu. Kirim password barunya. |
| Ganti password sendiri | Menu **Ganti password**. |
| Karyawan keluar | Menu **Pengguna** → **Nonaktifkan**. Ia tidak bisa masuk lagi; data yang pernah ia catat tetap ada. |
| Simpan cadangan | Menu **Pengguna** → **Unduh cadangan data**. Lakukan sebulan sekali, simpan di Google Drive perusahaan. |
| Lihat biaya AI | Menu **Pemakaian AI**. Batas pertanyaan bisa diubah di **Atur batas dan harga**. |
| Tidak ada sinyal | Tetap isi seperti biasa. Isian masuk **Antrean sinkron** dan terkirim sendiri saat tersambung. |

Hanya Manajer yang melihat menu Pengguna dan Pemakaian AI.

## Kalau ada masalah

| Gejala | Yang dilakukan |
|---|---|
| Web tidak bisa dibuka | Coba lagi 2 menit kemudian dan dari jaringan lain. Kalau masih mati, hubungi kontak di bawah. |
| "Perlu diperiksa" di Antrean sinkron | Buka antreannya, baca alasannya, perbaiki isian, lalu **Kirim ulang**. |
| Tanya OneFlow berkata batas tercapai | Tunggu besok, atau naikkan batas di **Pemakaian AI**. Layar lain tetap jalan. |
| Semua Manajer lupa password | Hubungi kontak di bawah; ia bisa membuat Manajer baru dari halaman pengaturan hosting. |

**Kontak bantuan:** _isi nama dan nomor WhatsApp orang yang memegang akun hosting._

## Yang berjalan sendiri

- **Pembaruan aplikasi** terpasang otomatis saat pengembang merilis versi baru.
- **Cadangan database harian** oleh penyedia hosting, bila memakai paket berbayar.
- **Pemantau** mengirim email bila web mati, bila sudah dipasang (lihat `DEPLOY.md`).

## Yang perlu diputuskan mitra satu kali

1. **Pemilik akun hosting.** Sebaiknya email perusahaan, bukan email pribadi pengembang.
2. **Pembayar tagihan bulanan** hosting dan API AI (Google).
3. **Kontak bantuan** bila web mati.
